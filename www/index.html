Moderne PDF-Dokumente aus strukturiertem Markdown

markpublish setzt Markdown-Kapitel in druckreife, hochwertige PDFs — Deckblatt, Verzeichnisse und Kopfzeilen entstehen automatisch.

$ pip install markpublish

FUNKTIONEN

Alles, was professionelle Dokumente brauchen

Kein Herumschlagen mit unzähligen CLI-Flags oder brüchigen LaTeX-Installationen.

📑

Ein Manifest für alles

Titel, Deckblatt, Inhaltsverzeichnisse, Kopf- und Fußzeilen sowie die Reihenfolge der Kapitel werden zentral in markpublish.yaml definiert.

📖

Teile, Kapitel & Trennseiten

Teile und Kapitel erhalten auf Wunsch stilvolle Trennseiten mit Untertitel, Zusammenfassung und eigenem lokalem Teil-Inhaltsverzeichnis.

🔢

Musterbasierte Nummerierung

Ein einziges Muster wie "1|.1|+", "A|.1|+" oder "I|1|.1|+" steuert die Nummerierung. Frei anpassbare Präfixe („Kapitel“, „Anhang“) und synchrone Verzeichnisse.

🎨

Themen in Typst

Mit markpublish export-template exportieren und anpassen. Schriftarten werden im Theme mitgeliefert — das Dokument sieht überall exakt identisch aus.

✨

Markdown, das mehr kann

GitHub-style Alerts ([!NOTE], [!WARNING]), Fußnoten, Aufgabenlisten, Definitionslisten, LaTeX-Mathe und erstklassiges Code-Highlighting.

🌍

Zweisprachig gedacht

Dokumentensprache steuert Silbentrennung und Bezeichnungen („Kapitel“, „Abbildung“). Das CLI folgt wahlweise dem System oder --ui-lang.

📦

Null externe Abhängigkeiten

Kein separates Typst-Binary oder Pandoc-Setup nötig. Der Typst-Compiler wird direkt über offizielle Python-Wheels eingebettet.

🚀

Selbstdokumentierend

markpublish cheatsheet und markpublish manual generieren die Handbücher direkt aus dem installierten Paket — immer versionsgenau.

SCHNELLSTART

In 3 Schritten zum ersten Dokument

Installieren, Projekt anlegen, PDF bauen — fertig.

bash — markpublish workflow
# 1. markpublish installieren (benötigt Python 3.10+)
$ pip install markpublish
 
# 2. Projekt anlegen — erzeugt markpublish.yaml und welcome.md
$ markpublish init mein-dokument
[OK] markpublish-Projekt eingerichtet in mein-dokument
markpublish build mein-dokument/markpublish.yaml erzeugt Ihr erstes PDF.
 
# 3. Druckreifes PDF kompilieren (Dateiname aus dem Dokumententitel)
$ markpublish build mein-dokument/markpublish.yaml
[OK] PDF erfolgreich erzeugt: mein-dokument/mein_dokument.pdf
